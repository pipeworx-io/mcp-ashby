# mcp-ashby

Ashby MCP Pack — wraps the Ashby ATS API

Part of the [Pipeworx](https://pipeworx.io) open MCP gateway.

## Tools

| Tool | Description |
|------|-------------|

## Quick Start

Add to your MCP client config:

```json
{
  "mcpServers": {
    "ashby": {
      "url": "https://gateway.pipeworx.io/ashby/mcp"
    }
  }
}
```

Or use the CLI:

```bash
npx pipeworx use ashby
```
